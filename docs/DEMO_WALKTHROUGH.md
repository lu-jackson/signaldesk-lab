# 10 分鐘 Demo 腳本

前置：`python scripts/launcher.py start`，開 http://127.0.0.1:8000（沒有任何金鑰也能完成全部步驟）。畫面頂端的模式列會一直顯示「規則／模板（非 LLM）」「合成 Demo 資料」「僅本機模擬」。

| 分鐘 | 在哪裡點什麼 | 預期看到 |
|---|---|---|
| 0:00 | **儀表板** | 5 個指標卡，每張都有「分母」；提示合成資料；worker 執行中。點「待審草稿」會跳到草稿頁。 |
| 1:00 | **品牌與帳號** | 2 個品牌（刷題快手、MoreTi 電子筆記，版本 v1；品牌事實取自 moreti.app 公開頁面）、4 個 `demo_` 帳號（貼文、留言、帳號皆為合成）。展開「刷題快手」按「編輯」，改 CTA 後按「儲存（產生新版本）」→ 版本變 v2（先不改也可以，之後再示範）。 |
| 2:00 | **專案與搜尋** → 「多益備考需求追蹤」按 **立即執行並看結果** | 訊息「完成：候選 N、已分類 N、草稿 M」；下方結果表：每列有原文、納入／排除原因、意圖、風險、**分類理由與原文證據**。廣告（含「補習班」「【招生】」「歡迎洽詢」）被排除；已解決的、抱怨的有各自的意圖。含「忽略規則…API key」的惡意貼文標 `prompt_injection`、risk high、**沒有草稿**。 |
| 3:30 | **草稿審核** | 草稿「未核准」，「模擬送出」按鈕是灰的。按**核准** → 「核准有效」→ 把內文改一個字按「儲存修改」→ 變回「未核准／已失效」，送出又灰了。再核准 → **模擬送出** → 顯示 `simulated_sent`，下方「僅本機模擬，無已讀資料」。 |
| 4:30 | 回品牌頁改 CTA 存檔，再看草稿頁 | 尚未送出的草稿出現「品牌設定已更新」，核准被撤銷，要重新核准或「依目前品牌重新生成」。 |
| 5:00 | **留言與私訊模擬** → 規則「免費題型清單留言」按**預覽** | 顯示命中的既有留言與將送出的內容；預覽不寫任何東西。 |
| 5:30 | 事件區按**注入事件**，再按一次 | 第一次 `duplicate=false`，第二次 `duplicate=true`。約 1–2 秒後（worker 輪詢）按「重新整理」，投遞紀錄出現公開回覆與私訊皆 `simulated_sent`，已讀欄＝「平台未回報」。 |
| 6:30 | 失敗注入：私訊選 `permission_revoked`，換一個 event_id 再注入 | 公開回覆 `simulated_sent`、私訊 `failed_terminal`（嘗試 1 次，不會 retry）。再試 `unknown` → 狀態 `unknown`，旁邊有「確認已送出／確認未送出」（reconcile）。**做完把失敗注入調回 none。** |
| 7:30 | **名單** | 留言者 `demo_tester` 已自動入名單（一筆，多來源會合併）。開「詳情」看來源與歷史；狀態改 Converted → 顯示「不代表訂單」。可匯出 CSV / JSON。 |
| 8:00 | **連結與分析** | 建立追蹤連結（目的地預設本機 landing）；點短連結（新分頁）再「重新整理」→ 點擊 +1。試輸入 `javascript:alert(1)` → 被拒。切換「近 1 天／14 天」→ 卡片與長條圖加總一致；沒資料的區間顯示「沒有資料」而不是 0%。貼文監測標示「合成」。 |
| 9:00 | **AI 助手** → 預設範例句按「送出給助手」 | 標示「scripted planner（非 LLM）」；trace 顯示 list_projects → get_brand → search_demo_posts → classify_posts → prepare_draft ×3；結尾「零份送出」。到草稿頁可看到 3 份 `created_by agent:…` 的草稿。 |
| 9:40 | 助手輸入「把 demo_vip01 標記為 Qualified」 | 只產生**提案**（pending），名單裡還沒有此人；按「確認」才生效。 |
| 10:00 | **設定與用量** | 三個獨立開關；Anthropic「未配置」；用量帳本顯示 reserve/settle/release，標明無現金價值。**工作與事件**頁可看到所有工作狀態。 |

選講：在「設定」把 AI 切到 anthropic 且沒有 key → 跑專案，分類會顯示明確的「未配置」錯誤，**不會**偷偷用 Demo 補上；切回 demo 即可。
